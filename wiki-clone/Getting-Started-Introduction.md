# Introduction

9A Smart Connect streamlines the integration of electronic documentation between Microsoft Dynamics 365 Finance & Operations and external applications, using a wide range of protocols.

As the *cloud* becomes central to modern implementations, Smart Connect embraces cloud-based resources such as Azure file storage and customer/vendor APIs for orders and master data. Through a single, centralised dashboard it lets you access these resources with ease, giving your organisation robust and reliable processing.

> **Info: Who is this manual for?**

> It is written for two audiences. The **Functional guide** explains, in business terms, how to configure and operate Smart Connect using the labels you see on screen. The **Technical reference** documents the underlying classes, tables and flows (prefix `NAN`) for developers and solution architects.

### What you can do with it

-   **Export** documents and data from D365 F&O — invoices, orders, payment files, master data — to files, APIs, EDI partners or cloud storage.
-   **Import** documents and data into D365 F&O — sales orders, purchase invoices, bank statements — from files, APIs or capture platforms.
-   **Leverage the standard platform**: Data Management Framework (DMF), Electronic Reporting (ER), print destinations and custom X++ logic are all valid data handlers.
-   **Operate reliably** with queueing, automatic retries, event-driven and scheduled processing, logging and Application Insights telemetry.
