# Menu & workspace

9A Smart Connect is a module within D365 F&O. All setup, logging and related functionality is reachable from the **9A Smart Connect** workspace and the module menu.

### The 9A Smart Connect workspace

The workspace is the day-to-day landing page. It surfaces the most-used forms as tiles and lists.

**9A Smart Connect**

#### Connectors

Connecters are used to connect to external applications.

#### Processors

Processors run business processes using connectors.

#### Logs

Logging of the processors.

#### Error logs

Jump straight to logged errors.

Additional tiles: `AR Parameters` `AP Parameters` `DM Projects` `DM Execution History` — plus a **Lists** tab showing your **Electronic Reports** configurations.

> **Info: Verified against the live environment**
>
> The tile names and help texts above are taken directly from the running `NANWorkspace` form (caption “9A Smart Connect”).

### Module menu structure

The full menu (`NANMenu`) is organised into four practical areas:

| Menu area | Contains | Purpose |
| --- | --- | --- |
| **Definitions** | Connectors, Processor definitions, Process groups | Design your integrations. |
| **Inquiries & reports** | Queue, Events, Logs, Data Management import | Monitor and troubleshoot. |
| **Periodic tasks** | Run processors, Clear logs, Queue cleanup, Electronic reporting process | Schedule and run in batch. |
| **Setup** | Parameters, Business process, Attributes, Placeholders | One-time and global configuration. |
